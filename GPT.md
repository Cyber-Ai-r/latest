# Project Guidance

This repository is the starting point for the Latest project.

## Development Guidelines

- Keep changes focused and easy to review.
- Document setup and usage instructions as the project grows.
- Do not commit secrets, API keys, or local environment files.
- Add tests for new behavior when the project gains application code.

## Git Workflow

- Use clear, descriptive commit messages.
- Work on branches for non-trivial changes.
- Verify changes locally before pushing.
